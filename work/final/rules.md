# Final case rules (Freya Bank, credit card statement debt): summary
Sources: BRIEF.md, analysis 2026-10-08 (wins over 2026-09-02), decisions recap 2026-10-09 (wins over the analysis), service contract 2026-10-01, example-scenarios.md.
1. Language: Turkish. Fixed lines are quoted in the analysis (sections 3-10). Overrides from the 9 Oct recap: THREE calming replies before handing an angry caller to an agent (not two); never read more than the last 4 digits, even if production returns the full number; third silence -> "Sesinizi alamadığım için görüşmeyi sonlandırıyorum." (no main menu); out-of-scope question -> "Size bu konuda yardımcı olamıyorum. Sizi ana menüye aktarmamı ister misiniz?"
2. Variables: customerNumber (8 digits, never asked for), now (Istanbul ISO time; every date decision uses it).
3. Opening: no identity check (the IVR has already done it). One card -> read it at once. Several -> "Hangi kartınızın borcunu öğrenmek istersiniz? Örneğin, X veya Y diyebilirsiniz."
4. Third party: only the caller's own cards; another person's card -> security line, no info, back to the IVR login.
5. Identity: none (done by the IVR). Duplicate cards: name -> last 4 -> last 6 -> full number.
6-8. Reading order: card intro + statement date, TL (3 cases: nothing paid / minimum paid / less than minimum paid), then USD, EUR, GBP, then one no-debt sentence (blocks missing from the response are left out), automatic payment, due date ("bugün" when it is today). Amounts are spoken in words, currencies by full name. The reading is computed in code (cards_balance post-hook / read1 node).
9. After the reading: "another card?" (if the caller has several cards) -> the offer, which depends on whether an e-mail is registered (contact.email.get is called before the offer) -> e-mail / week change / main menu / agent.
10. Writes: statement.pdf.send (latest statement only, registered address only, explicit yes, up to 3 per call); statement.week.change (only after the decide preview + a clear "evet"; hedged answers are not a yes).
12. Endings: main menu / agent / IVR login / hangup (route_call tool; there is no bank service for the hand-off, so the call goes to the mock's /health endpoint as a hand-off marker). Sentences are taken from analysis section 10.
13. Tools: POST {mock}/voice/v1/{cards.list,cards.balance,statement.week.get,statement.week.decide,statement.week.change,contact.email.get,statement.pdf.send}; envelope {data, call}; success = HTTP 200 + returnCode "1"; errors 400/404/500 -> service error -> agent (cards.list 404 = no eligible card -> main menu).
